## Decky preview for Steam Deck and Bazzite

[Download the Decky plugin preview](https://github.com/AhmxdNYC/discord-handheld-controls/releases/download/v6.30.0/HandheldControls-Decky.zip). It can prepare Vesktop controller support and add a **Discord — Handheld Controls** shortcut to Steam. Install Decky separately first, then use its developer ZIP installation workflow.

This preview has offline installer tests and a built frontend, but has not been tested inside Decky on a handheld. It uses native controller input; the optional controller bridge and automatic Steam Input layout setup are not included. [Installation, source builds, removal, and limitations](docs/decky.md).
